REGRAS
----------------------------------------------------------------------------------

1. Cadastro de Monitores
1.1 O professor deve selecionar previamente a turma na qual deseja cadastrar o monitor.
 1.2 Erro: Tentativa de cadastro sem turma selecionada → “Selecione uma turma antes de cadastrar.”
 1.3 Erro: Monitor já cadastrado nessa turma → “Monitor já existe na turma selecionada.”
 1.4 Sucesso: “Monitor cadastrado com sucesso!” → Exibir lista de monitores e opção Cadastrar novo monitor.
 1.5 Validação obrigatória de campos (nome, matrícula, turma).

⚙️ 2. Forma de Alocação
2.1 Opções disponíveis:
Aleatória: Monitores escolhidos aleatoriamente, alunos em ordem alfabética.
Manual: Professor define manualmente cada alocação.
2.2 Regras de funcionamento:
Botão “Alocar” só é habilitado após selecionar o modo (aleatório ou manual).
O sistema deve verificar se há monitores cadastrados antes da alocação.
2.3 Mensagens:
Sucesso: “Alocação realizada com sucesso.”
Erro: Nenhum monitor cadastrado → “Cadastre monitores antes de realizar a alocação.”


🧩 3. Correção Manual de Alocação
3.1 Exibir lista completa de monitores e seus alunos atuais.
 3.2 Erro: Mesmo monitor alocado duas vezes → “Monitor já possui alunos alocados.”
 3.3 Erro: Existem alunos sem monitor → “Há alunos não alocados. Corrija antes de confirmar.”
 3.4 Sucesso: “Alocação corrigida com sucesso.”
Após confirmar, notificar automaticamente alunos e monitores.


🔁 4. Realocação de Alunos
4.1 Critérios de realocação:
Priorizar monitor com menos alunos.
Caso haja empate, usar ordem alfabética dos monitores.
4.2 Erros e Regras:
Erro: Monitor atingiu limite máximo de alunos → “Limite de alunos por monitor atingido.”
Erro: Monitor sem nenhum aluno → “Todos os monitores devem possuir ao menos um aluno.”
Sucesso: “Realocação concluída com sucesso.”
Exibir nova distribuição e notificar monitores/alunos envolvidos.


🔔 5. Notificações
5.1 Após qualquer alocação ou correção:
Ao monitor: lista dos alunos sob sua responsabilidade.
Ao aluno: nome e contato do monitor responsável.
Notificação realizada com um único botão de envio geral (“Enviar notificações”)

 Regras Adicionais
Limite configurável de alunos por monitor (definido por turma).
Sistema deve impedir o salvamento parcial (nenhum aluno pode ficar sem vínculo).
Deve existir um botão de revalidação geral, que verifica automaticamente:
se todos os alunos estão alocados;
se todos os monitores possuem alunos;
se não há duplicidades.

PROMPT PARA IMPLEMENTAÇÃO DO SISTEMA DE ALOCAÇÃO
Objetivo: Criar um sistema modular para gerenciamento de monitores e alunos, com regras de alocação controladas exclusivamente por professores.

------------------------------------------------------------
ESTRUTURA DO PROJETO

Separar o código em módulos e entidades, conforme abaixo:

Entidades (models/)
1. Professor
   - id, nome, email, senha
   - turmas: relação 1:N com Turma

2. Monitor
   - id, nome, matrícula, turma_id (FK)
   - alunos_alocados: relação N:M com Aluno

3. Aluno
   - id, nome, matrícula, turma_id (FK)
   - monitor_id (FK)

4. Turma
   - id, nome, professor_id (FK)
   - monitores, alunos

5. Notificação
   - id, tipo (“monitor” | “aluno”), mensagem, destinatário_id, status (“pendente”, “enviado”)

------------------------------------------------------------
Módulos (separar em pastas)

1. auth/
   - Login e autenticação (Professor, Aluno, Monitor)
   - Redirecionamento automático de tipo de usuário

2. cadastro_monitores/
   - Função: cadastrar e listar monitores
   - Regras: evitar duplicidade, turma obrigatória

3. alocacao/
   - Submódulos:
     - random_allocation: alunos em ordem alfabética, monitores aleatórios
     - manual_allocation: alocação via interface visual
   - Regras:
     - Todos alunos e monitores devem estar alocados
     - Apenas o professor pode executar

4. correcao_manual/
   - Interface drag-and-drop para correção
   - Verificações: duplicidade, alunos sem monitor
   - Notificação automática ao salvar

5. realocacao/
   - Função: redistribuir alunos automaticamente
   - Critérios:
     - Menos alunos → prioridade
     - Empate → ordem alfabética
   - Regras:
     - Limite máximo de alunos por monitor
     - Nenhum monitor pode ficar sem aluno

6. notificacoes/
   - Um botão único “Enviar notificações”
   - Envia para todos (alunos e monitores) as informações da alocação final
